## Implementation Summary

- Replaced the deterministic rerun scaffold with a real independent second-run comparison when `--deterministic-rerun` is set.
- The first validation pass now keeps full per-model reports and resolved source metadata in memory.
- Terminal humanoid profile statuses (`passed`, `partial_passed`) are rerun through `_validate_entry()` with the same reproduction command, then compared on:
  - report `status`;
  - `deterministic_hash`;
  - rank summaries;
  - canonical projection residual/status summaries;
  - semantic map resolution and semantic site evidence.
- `source_unavailable` and `license_blocked` entries are explicitly marked un-compared and are not counted as deterministic pass.
- `negative_control_passed` entries do not have humanoid profile hashes, so they compare only load status and runtime dimensions.
